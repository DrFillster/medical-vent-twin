Mechanistic Lung Simulator v0.4.5

Three-compartment mechanical-ventilation simulator — finite-capacity exponential elastic law, Newton-Raphson implicit solver with conservation by construction, bounded recruitment kinetics with feasibility floor. Phenotypes are mechanical constructs labeled by their recruitable pool size, not validated clinical ARDS severity grades. Educational exploration prototype; not a clinical decision tool; not a patient-specific digital twin.

What changed since v0.4.4.1

  • Browser bundle contract repaired: reproducible dependency-free IIFE build replaces the mismatched IIFE/ES-module import.
  • Worker receives an explicit scenario (initial recruitment + PEEP), controller/tracker rollback on rejected steps, runFor abort on failure.
  • Mobile layout stacks panels below 700 CSS px; controls ≥ 46 px high, 16 px text; waveforms resize labels to panel width.
  • Plateau and driving pressure withheld unless a suitable settled VC pause exists; PC mode does not fabricate an occlusion plateau.
  • Three named starting examples; explicit, editable initial recruitment fraction per phenotype.
  • Settings use mL for tidal volume and L/min for flow with conversion at the UI boundary.
  • Gas exchange controls omitted in this UI (gas exchange code retained in source for legacy use, disabled in browser runs).
  • Test runner fails on crashed / timed-out / signaled / empty test processes.
  • Constitutive mechanics, recruitment equations, phenotype parameters — unchanged. See history/v0.4.4.1/ for the prior bundle.
