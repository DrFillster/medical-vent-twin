# Quantitative Physiology Holds

Date: 2026-10-10

## Aortic CaO2-content chemoreflex

Status: HOLD.

Reason:
- a distinct quantitative aortic oxygen-content controller has not yet been selected with a complete primary-source equation and parameter set;
- adding it now could double-count the peripheral O2 chemoreflex already represented by the Ursino/Magosso controller.

Release condition:
- primary-source equation;
- parameter units;
- defined carotid-versus-aortic ownership;
- validation experiment demonstrating added value without double-counting.

## Temperature / fever chronotropy

Status: HOLD.

Reason:
- no source-backed dynamic temperature-to-SA-node/autonomic mapping has yet been selected for this model;
- fever-related HR changes interact with metabolic rate, inflammation, autonomic tone, and volume state.

Release condition:
- published quantitative dynamic relationship;
- explicit population and temperature range;
- interaction rules with sepsis/autonomic state;
- shadow validation before any HR effect.

## Rule

Neither feature may be implemented as a fitted gain solely to create a clinically familiar response.
