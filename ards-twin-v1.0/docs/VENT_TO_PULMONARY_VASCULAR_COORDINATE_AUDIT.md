# Vent to Pulmonary Vascular Coordinate Audit

Date: 2026-10-11
Status: integration audit
Candidate downstream model: Karamolegkos/Albanese/Chbat pulmonary circulation

## Question

Can Vent's current `simulation.state.totalVolume` be used directly as the source-model
alveolar volume `V_A` required by Karamolegkos Eq. 3?

## Answer

**No. Not yet.**

Karamolegkos Eq. 3 uses absolute alveolar volume relative to a nominal functional
residual capacity:

```
R_pal(V_A, sh)
  = R_pp,tot / [2 * (1 - sh)] * (V_A / FRC_nom)^2
```

with `FRC_nom = 2.25 L`.

Vent's current volume state is an elastic compartment volume generated by its own
finite-capacity constitutive law:

```
Vmax_i = availability_i * capacity_i

p_el,i = -K_i * ln(1 - V_i / Vmax_i)

P_alv,i = AOP + p_el,i
```

The Vent volume coordinate is therefore model-internal elastic gas volume. It has
not been defined or validated as absolute lung gas volume at FRC.

## Why the tempting adapter is not authorized

The adapter

```
V_A = FRC_nom + Vent.totalVolume
```

would be dimensionally valid but physiologically unverified.

It would silently assert that:
1. Vent zero volume equals Karamolegkos FRC;
2. Vent recruitment/derecruitment changes are represented on the same absolute
   lung-volume coordinate as the Karamolegkos model;
3. Vent's total elastic volume includes the same gas volume definition as the
   human CP model.

Those assumptions have not been established.

## What would authorize the bridge

One of these is required:

### Option A — redefine Vent volume with an explicit absolute-volume state
Introduce an authoritative FRC/reference-volume state and define every compartment
volume relative to that state with source-backed geometry and recruitment rules.

### Option B — derive an absolute alveolar volume from a validated respiratory model
Use a respiratory model whose state explicitly includes FRC and absolute alveolar
volume and map Vent mechanics to that state through a published relationship.

### Option C — fit the coordinate bridge to independent lung-volume data
This would require an identified dataset, explicit fitting method, uncertainty
analysis, and independent validation. It cannot be a convenience calibration.

## Current decision

Karamolegkos pulmonary vascular equations remain candidate-only.

The equations and source parameters are preserved and tested, but they do not yet
drive canonical PVR or PAP.

## Separate regional perfusion problem

Even after the global absolute-volume coordinate is solved, regional V/Q requires
an additional model for perfusion redistribution.

Human physiology establishes that:
- HPV diverts perfusion away from hypoxic lung regions;
- global hypoxia raises pulmonary vascular resistance and PAP;
- focal hypoxia can improve regional V/Q matching without necessarily producing
  the same global PAP response.

The Marquis/Beard VQ model provides an explicit mechanistic HPV formulation and
public source code, but it is a rat-lung model and includes fitted/engineering
parameters. Its human use therefore remains research-only until a human translation
is independently justified.

## Governing rule

Do not infer regional perfusion from `perfusionFraction * recruitment` as final
physiology.

Do not infer Karamolegkos absolute alveolar volume from Vent elastic volume without
a validated coordinate transform.


## v1.6 update — Option A implemented as a reference-anchored coordinate

The original prohibition remains unchanged:

```
V_A = FRC_nom + Vent.totalVolume
```

is still **not authorized**.

However, Option A is now implemented for cases in which an authoritative absolute alveolar volume is available at a Vent state observed at the same instant.

At a synchronized reference state:

```
V_A,ref       = source-qualified/measured absolute alveolar volume
V_Vent,ref    = Vent elastic distal volume at that same instant
```

Thereafter the candidate coordinate adapter uses only the volume change:

```
V_A(t) = V_A,ref + [V_Vent(t) - V_Vent,ref]
```

This does **not** assert that Vent zero equals FRC. It translates a distal gas-volume change after the two coordinates have been explicitly registered at one reference state.

Implementation:
- `src/v16_reference_anchored_alveolar_volume_adapter.js`
- `test/v16_reference_anchored_alveolar_volume_adapter.test.js`

Authority limits:
- the adapter is candidate-only;
- it fails closed without a source-qualified reference absolute volume;
- it does not solve the remaining global alveolar-pressure or pleural-pressure coordinate problem;
- it does not authorize use of Karamolegkos nominal FRC as an arbitrary patient-specific reference.
