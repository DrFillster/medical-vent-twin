# Owner decision required

No license is selected in this release candidate. Public availability of source
is not, by itself, an open-source license. The manuscript therefore does not
claim the artifact is open source.

The project owner should establish rights to the supplied and revised materials,
choose the desired software and documentation licenses, and add their actual
license texts and copyright notices before public distribution. This package
does not authorize an LLM to assert ownership, impersonate an author, or choose
a licensing policy on the owner's behalf.

The package includes citations to published work, not copies of the cited papers.
