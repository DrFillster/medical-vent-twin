# HumMod browser live-core milestone

Status: experimental engineering preview. Not clinically validated. Not for patient care.

## What changed

The Clinical Twin now has a browser-capable session API for the authored moderate/intermediate aspiration reference case using a **live reduced HumMod ARDS cardiopulmonary core** instead of fixed trajectory replay.

The live path preserves one persistent patient state and couples:

1. Vent compartment mechanics, recruitment, PEEP, FiO2 and VC-AC delivery;
2. a passive thorax / pleural-pressure bridge;
3. the reduced source-aligned HumMod circulation;
4. Vent recruitment/perfusion into the HumMod-derived pulmonary gas boundary;
5. the reduced HumMod gas / acid-base core.

The live session exposes dynamic PaO2, PaCO2, pH, MAP, pulmonary-artery pressure and cardiac output that advance after Vent interventions. These values are generated by the reduced coupled model rather than read from a fixed trajectory row.

## Deliberate limits

- This is **not the full HumMod runtime** and is never labeled as such.
- Live mode is currently restricted to `berlin-moderate-moderate-aspiration`.
- Live mode currently supports `VC_AC` only because the phase-1 Vent-to-core adapter uses delivered tidal volume explicitly.
- Thorax, circulation, metabolic, blood and environmental starting boundaries are explicit synthetic engineering assumptions carried forward from the gated cardiopulmonary benchmark. They are not inferred from Berlin severity and are not patient measurements.
- The passive-mechanics maneuver advances the systemic core across the maneuver interval using the final recent mean-airway-pressure state; sub-maneuver cardiopulmonary integration remains future work.
- No claim of clinical validation is made.

## Session API

`createBerlinLiveHumModSession(...)`
: Runs Vent + reduced HumMod ARDS core in one persistent session. No trajectory file is required.

`createBerlinClinicalTwinSession(...)`
: Preserves the existing validated trajectory import/replay pathway. Vent interventions do not alter the fixed systemic trajectory.

## Verification

The new focused test file adds five assertions covering finite live gas/hemodynamic outputs, persistent PEEP response, FiO2/VC changes, the explicit VC-only guard, and reference-case restriction.

Local full-suite result after this change: **314 passed, 0 assertion failures, 0 failed files**.
